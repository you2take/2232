About / Yuto Takegishi

Ordinary is
boring.

ジオコード、クリエイティブブティック、電通グループで、WebマーケティングからCMと連動するデジタル施策の企画・制作まで経験。株式会社タガタメの創業・取締役を経て、2021年に株式会社2232を設立。Webの戦略設計から企画・制作ディレクション、マーケティングまで手がける。ニュートラルワークス取締役CCOを務めるほか、複数の事業会社の創業・運営にも携わる。

We create — / 01

Websites

Webサイト制作

事業の目的と、訪れる人が知りたいことを整理するところから始めます。コーポレートサイト、採用サイト、ブランドサイトなど、伝える内容に合わせて構成・デザイン・実装を設計。公開後の更新まで見据えて制作します。

We create — / 02

Branding

ブランディング

企業やサービスが大切にしていることを掘り下げ、誰に、何を伝えるかを定めます。コンセプトや言葉、ロゴ、色、書体を整理し、Webや印刷物など、ブランドに触れる場所で一貫した印象をつくります。

We create — / 03

Art Direction

アートディレクション

伝えたい内容を、どんな表現で見せるか。その方針を決め、写真・映像・文字・レイアウトの役割を組み立てます。企画から制作の現場まで全体を見渡し、細部の判断を重ねて表現を仕上げます。

We create — / 04

Creative Systems

クリエイティブシステム

デザインのルールや共通パーツ、更新の手順を整えます。複数のページや媒体で表現を揃え、制作と運用をつなぐ仕組みを設計。担当者が変わっても、ブランドの表現を継続できる状態をつくります。

We create — / 05

Digital Experiences

デジタル体験設計

見る、触れる、選ぶ。その一つひとつの操作と、画面の応答を設計します。WebやARなどの特性を活かし、内容が自然に伝わる導線と動きを制作。使いやすさと、試してみたくなる楽しさを両立させます。

We create — / 06

Digital Marketing

デジタルマーケティング

届けたい相手と事業の目標を明確にし、検索・広告・SNS・コンテンツの役割を考えます。集客の施策と、訪れた先のWebサイトを合わせて設計。アクセスや反応を確かめながら、クリエイティブと導線を改善します。
